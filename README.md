# eRTMAC-NWIS — Nearby Wells Intelligence System
### Smart India Hackathon 2026 | Problem Statement: SIH 26121 | Oil India Limited

An AI-powered, real-time nearby wells intelligence and risk assessment platform designed for drilling operations in the Assam/Brahmaputra Basin.

---

> [!IMPORTANT]
> **[SYNTHETIC – DEMO DATA DISCLAIMER]**
> All well records, trajectories, geological formations, and historical drilling problem events generated by this system are synthetic and intended strictly for Smart India Hackathon demonstration purposes. Never use this data for actual field drilling operations.

---

## Architecture & Tech Stack (PERN)

- **Frontend:** Next.js 14 (App Router) + React + Tailwind CSS + Leaflet.js (CartoDB dark maps)
- **Backend:** Node.js 20 + Express.js REST API + Server-Sent Events (SSE)
- **Database:** PostgreSQL 15 + PostGIS 3 (Geospatial) + pgvector 0.7 (768-dim embeddings)
- **AI & RAG Engine:** Google AI Studio — Gemini 1.5 Flash + `text-embedding-004`
- **Document Processing:** Pure JavaScript worker (`pdf-parse` + `tesseract.js` OCR fallback)
- **Object Storage:** MinIO (Local S3-compatible)
- **Deployment:** 5-container Docker Compose setup

## Quick Start (Docker Compose)

### 1. Prerequisites
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (Windows with WSL2 backend or Linux/macOS)
- Node.js 20+ (optional, for local development outside Docker)
- Google AI Studio API Key from [aistudio.google.com](https://aistudio.google.com)

### 2. Configure Environment
Copy `.env.example` to `.env` and insert your Google AI Studio API key:
```bash
cp .env.example .env
```
Edit `.env`:
```env
GOOGLE_API_KEY=AIzaSy...your_gemini_key_here
```

### 3. Generate Seed Data (Wells, Events & Synthetic PDFs)
```bash
python scripts/generate_seed.py
```
This generates:
- `db/seed.sql` (50 Assam wells, 200 drilling events, 298 formation intervals)
- `synthetic_reports/*.pdf` (5 drilling completion reports with embedded incidents)

### 4. Launch Application
```bash
docker compose up --build
```

Wait ~60-90 seconds on first run for database initialization and image builds.

### 5. Access Endpoints
- **Frontend Dashboard:** [http://localhost:3000](http://localhost:3000)
- **Express API Health:** [http://localhost:8000/api/v1/health](http://localhost:8000/api/v1/health)
- **MinIO Storage Console:** [http://localhost:9001](http://localhost:9001) (User: `minioadmin` / Pass: `minioadmin`)

## Key Features

1. **Geospatial Offset Well Mapping:**
   - Real-time map rendering of active rig (default `OIL-W-042`) and offset wells in Assam Basin.
   - Interactive search radius circle (5, 10, 15, 25 km).

2. **Deterministic Proximity Risk Calculation:**
   - Evaluates 4 weighted factors:
     - Depth Proximity (35 pts, ±100m window)
     - Formation Match (25 pts, e.g. Barail tight sandstone target)
     - Historical Event Recurrence (20 pts)
     - Multi-incident Context (20 pts)
   - Real-time alert trigger when hazard score $\ge 40$.

3. **Live Drilling Simulation (Server-Sent Events):**
   - Simulates rig penetration rate (+0.5m every 3s).
   - Dynamically recalculates proximity hazards and streams live alerts to engineer console without WebSockets.

4. **Grounded AI RAG Assistant (Gemini 1.5 Flash):**
   - Answers questions strictly using verified historical records in pgvector.
   - Anti-hallucination safeguard: requires offset well citations or explicitly reports insufficient evidence.
   - Reranking formula: `0.60*vector_similarity + 0.25*depth_proximity + 0.15*formation_match`.

5. **Document Ingestion & Verification Pipeline:**
   - Automated ingestion of PDF daily drilling reports to MinIO.
   - Multi-tier text extraction (`pdf-parse` with `tesseract.js` fallback).
   - Structured event extraction into staging review queue (`EXTRACTED` $\to$ `APPROVED`).
